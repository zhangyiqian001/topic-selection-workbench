# v0.1.0 · 首次版本发布

日期：2026-10-27。本地单人AI科普选题工作台的首个可运行基线。

## 发布内容

多平台采集、SQLite、定时去重、指标快照；抖音24行业一日榜、B站UGC分区榜、小红书公开热点和话题快照；RSSHub七家厂商订阅与通用RSS/Atom；自动优先分v2、联动筛选、发布时间回退、标签去重和较大字号；选题证据、人工研判、来源核验、历史及备份恢复。

## 安装与迁移

Node.js 24，执行`npm ci`、`npm run build`、`npm start`，访问本机4173。首次创建数据库与初始来源。已有用户保留原`data/`，升级前导出JSON备份。

Git不含个人数据库、额外订阅配置、截图或依赖；AIHOT等额外添加来源随数据库备份迁移。Git不能替代数据备份。

## 已知限制

小红书公开多行业笔记榜尚未稳定接入；豆包/Kimi/xAI订阅为官方开源仓库，非产品新闻。来源可能缓存或限流，评分不预测播放量、不自动核实事实。入选仍需人工核验和深度评分。

不含自动视频制作、登录采集、发布、多用户及云同步。项目尚未指定开源许可；第三方网站解析资源的分发授权需在对外公开前另行确认。

## 验证与发布方式

发布前语法检查、36项单元测试、生产构建及10项浏览器测试均通过，使用隔离数据库。GitHub工作流已配置，尚未在远程执行。来源曾在本机实测，未来可用性以日志为准。
